## 📊 Smart Real Estate Price Analysis

### 📌 Project Overview
This project analyzes house prices using Python and data visualization techniques. It explores the relationship between house prices and features such as bedrooms, bathrooms, and living area.

### 🎯 Objectives
- Analyze house price distribution.
- Study the relationship between house features and prices.
- Handle missing values in the dataset.
- Visualize data using charts.

### 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

### 📂 Project Files
- `Smart_Real_Estate_Price_Analysis.ipynb` — Python notebook containing the analysis and code.
- `Smart_Real_Estate_Price_Analysis.html` — HTML version of the notebook for viewing in a browser.
- `kc_house_data_NaN.csv` — House sales dataset.

### 🚀 How to Use
1. Download the project files from this repository.
2. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
3. Upload the dataset CSV file.
4. Run the notebook cells to perform the analysis.
5. Open the HTML file in a web browser to view the exported notebook.

### 📈 Key Analysis
- Distribution of house prices.
- Bedrooms vs. house prices.
- Bathrooms vs. house prices.
- Living area vs. house prices.

### 📝 Conclusion
This project helps explore housing data and understand how different property features relate to house prices.
